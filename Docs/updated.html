AMU System — Full Schema

Access Control (person, office, user, role, permission) + KPI Monitoring (kpis, user_kpis, reporting_periods, performance)

person is the source of truth for identity. office and role are both self-referencing trees, so the org chart and the permission hierarchy can nest arbitrarily deep. user is the hub: it ties a person to an office, carries roles, and is the same user that user_kpis assigns KPI targets to below — one system, one identity, everything else layered on top.
